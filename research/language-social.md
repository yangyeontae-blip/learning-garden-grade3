# 국어·사회·영어 학습자료 조사 및 검증 기록

검토일: 2026-10-29. 산출물: `dist/data/language-social.json`.

## 실제 산출물과 검사

- 국어 26개, 사회 16개, 영어 16개 = **58개 학습페이지, 174문항**.
- 페이지마다 설명 2문단, 예시, 연습문제 정확히 3개, 답·해설, 코드·출처를 수록했다. 모든 활동 문제에는 수행 안내와 확인 기준이 있다.
- 객관식 정답은 보기 문자열과 일치한다. 활동·표현 문제의 답은 예시이며 다른 표현을 틀렸다고 판정하지 않는다.
- 모든 페이지의 `standardCodes`와 `verifiedStandards[].code`가 일치함을 검사했다.
- 영어 16개 전부 영어 음성 대본 `speech.text`와 `lang: en-US`가 있다. 브라우저 음성합성용 창작 대본으로, 교과서 음원이나 원어민 녹음이 아니다.

## 교육과정 MCP 사용

실제 연결된 MCP의 `get_learning_roadmap`으로 국어·사회·영어 3~4학년군 전체 코드 구조를 조회했다. `get_standard(4국05-04)`와 연결된 `get_topic(kr.mt.korean.literature.3-4.4guk0504.01)`로 코드→주제→평가 초점 구조를 확인했다. 세부 코드는 설치 패키지의 `standard-texts.json`도 참고하고, 인용한 모든 기준을 공식 PDF 본문과 대조했다.

MCP의 3~4학년군 전체를 3학년으로 간주하지 않았다. 국어는 국정 3학년 양 학기 단원별 기능, 사회는 공개 3학년 목차의 네 대주제, 영어는 두 출판사 3학년 목차의 공통 의사소통 기능과 명시한 보충 주제로 범위를 배정했다.

## 공식 원문 직접 확인과 2024 일부개정 대조

NCIC PDF를 직접 내려받아 PyMuPDF로 성취기준 본문을 읽고 코드·본문·파일 기준 페이지 번호(1부터 시작)를 저장했다. 줄바꿈·공백만 정리했으며 다음 항목 제목이나 해설은 기준 문구에 넣지 않았다.

| 교과 | 직접 읽은 공식 URL | 인용 페이지 |
|---|---|---|
| 국어 | https://ncic.re.kr/inv/org/download.do?year=2022&seq=10003553&orgType=ogi4 | PDF 26 듣말, 28 읽기, 30 쓰기, 32 문법, 33 문학, 34 매체 |
| 사회 | https://ncic.re.kr/inv/org/download.do?year=2024&seq=10004260&orgType=ogi4 | PDF 25~28: 4사01~04 |
| 영어 | https://ncic.re.kr/inv/org/download.do?year=2024&seq=10004085&orgType=ogi4 | PDF 16 이해, 18 표현 |

처음 확인한 2022 사회(10003800)·영어(10003794) PDF 표지는 교육부 제2022-33호였다. 후속 개정 확인을 위해 [NCIC 통합검색](https://ncic.re.kr/srch/result_more.do?cate=attach&order=desc&page=6&search=2022%EA%B0%9C%EC%A0%95&sort=date)의 실제 첨부파일 내려받기 인수에서 2024판 파일 번호를 확인했다. 영어 PDF는 검색 결과 5페이지, 사회 PDF는 6페이지에 있었다.

**2024판 표지에 ‘국가교육위원회 고시 제2024-3호 일부개정 포함’이 표시됨을 직접 확인했다.** 이번 자료가 사용하는 사회 10개·영어 19개 고유 기준을 추출해 2022판과 공백을 제외하고 대조했으며 모두 동일했다. 사회·영어의 `sources`와 `verifiedStandards`는 최종적으로 2024판 URL을 가리킨다. 국어는 별책 5의 2022-33호 기준을 사용한다. 모든 교과의 모든 후속 법령을 검증했다는 의미는 아니다.

### 발견하고 보정한 MCP 추출 오류

사회 `4사01-01`·`4사01-02`는 MCP 원문에 기준 자체 대신 해설이 들어 있었다. 원 PDF의 기준 코드에는 일반 하이픈 대신 en dash가 쓰여 있었다. 이를 일반 코드 형태로 정규화하고 실제 기준 본문으로 교정했다. 단어 중간 줄바꿈으로 생긴 ‘탐 색’, ‘파 악’, ‘설명 한다’ 같은 표시도 원문 단어에 맞게 정리했다.

## 검증 범위와 한계

- 학년군 코드와 3학년 배정 근거를 구분했다. 학교·출판사별 진도는 다를 수 있고 창의적 체험활동은 이번 범위 밖이다.
- 전체 연간 핵심 주제를 학습 목표별로 요약한 자료다. 전체 교과서의 모든 차시·작품·단어·평가를 대체하거나 세 문항만으로 성취기준 전체를 평가하지 않는다.
- 국어·사회 조사·표현 활동에는 실제 수행 안내와 확인 기준을 제공했다. 지역이나 경험에 따라 다른 답도 가능하다.
- 영어에는 축약형·비축약형과 개인 상황에 따른 다양한 유효 답이 있다. 자유 답안의 의미나 원어민 발음을 자동 판정하지 않는다.

# 도덕·체육·음악·미술 학습자료 근거와 범위

확인일: 2026-10-29. 산출물: `dist/data/arts-ethics.json`, 46개 학습페이지·138개 창작 문항.

## 자료 사용 방식

- 교육과정 MCP `get_learning_roadmap`으로 네 교과의 3~4학년군 구조를 확인했다. 대표 기준 [4도02-02], [4체02-03], [4음01-02], [4미02-03]의 `get_standard`·`get_topic`을 직접 조회해 기준-세부 주제-관찰 증거 연결을 확인했다.
- MCP 패키지의 메타데이터에서 NCIC 공식 PDF URL을 확인하고 네 PDF를 실제 다운로드했다. PyMuPDF로 PDF 전체를 읽고 사용하는 53개 성취기준의 코드·원문·PDF 페이지를 대조했다. 모든 lesson의 `verifiedStandards`에 해당 원문·공식 URL·실제 PDF 페이지 번호(인쇄 쪽수 아님)를 기록했다.
- 설명·사례·연습문제는 새로 작성했다. 교과서 제재곡의 가사·악보·삽화·문제를 복제하지 않았다. 수행 문항은 모두 예시 답안과 관찰 가능한 확인 기준을 제공한다.
- `standardCodes`는 국가 교육과정의 3~4학년군 코드이다. 코드의 ‘4’가 4학년 전용이라는 뜻은 아니며, 3학년 배정은 아래 교과서 공개 자료로 별도 확인했다. 한 학습페이지가 성취기준의 모든 수행을 완전히 평가한다는 뜻도 아니다.

## 3학년 주제 배정 근거와 커버리지

### 도덕: 10페이지

실제 열람: [비바샘 2022 국정 도덕 3 공개 단원 목록](https://v.vivasam.com/educourse/index.do?textbookCd=106332). 페이지에 `[2022] 도덕 3`로 명시된 교과서를 확인했으며, 로그인 보호 교수자료를 내려받지 않았다.

실제 열람한 2022 자료:

- [비상 체육 3·4 공개 목차 PDF](https://dn.vivasam.com/vs/promotion2022/830/index/download/%EC%B4%88%EB%93%B1%20%EC%B2%B4%EC%9C%A1%2034%ED%95%99%EB%85%84.pdf)

두 출판사의 3학년 공통은 운동·스포츠 기본 움직임·표현이다. 운동에는 기본 체력과 건강 습관이 배치되며 출판사에 따라 3·4학년 비중이 다르다. 자료는 나에게 맞는 운동(pe-01~03), 이동(pe-04), 비이동(pe-05), 조작(pe-06), 움직임 연결·게임 규칙(pe-07), 움직임 요소와 표현(pe-08~10)을 다룬다. 수영·구르기·도구 타기처럼 지도자와 시설이 필요한 실제 수행을 혼자 하도록 유도하지 않는다. 온라인 자료의 연습은 실기 수업 전체를 대신하지 않으며 기록으로 실기 성취를 단정하지 않는다.

## 검증 결과와 공개 표시 원칙

- JSON 파싱, 중복 ID 없음, 페이지마다 설명 2문단 이상·문제 정확히 3개·정답과 해설 존재, 객관식 답이 보기와 정확히 일치함을 확인했다.
- 46개 페이지의 모든 `standardCodes`에 대응하는 `verifiedStandards`가 존재한다. 53개 고유 공식 성취기준의 원문과 PDF 페이지를 확인했다.
- 수행 문제는 학습자마다 다른 답이 가능하므로 모두 예시 답안·확인 기준으로 표시해야 한다. ‘자동 채점 완료’나 ‘성취기준 완전 이수’라고 표현하지 않는다.
- 예체능의 학기는 출판사·학교마다 다르게 배정될 수 있어 모두 `semester:year`이다. 이에 반해 국정 도덕의 단원별 배정은 1·2학기로 표시한다.
- ‘3학년 전체’의 범위는 이 대응표의 연간 기본 주제이며 모든 출판사의 제재·차시·실기 활동을 빠짐없이 복제한 자료라는 의미가 아니다. 학생 실제 수행 평가는 교사와 함께 확인해야 한다.

## 2024 음악과 일부개정 추가 대조 (2026-10-29)

상위 검토에서 국가교육위원회 고시 제2024-3호가 음악과 별책 12를 일부 개정한 사실을 확인하여 추가 점검했다.

- 고시 확인: [국가교육위원회 고시 제2024-3호 전문, 국가법령정보센터](https://www.law.go.kr/flDownload.do?flSeq=143731563), 2024-08-16.
- 실제 대조한 개정 원문: [NCIC 2024 일부개정 음악과 교육과정 PDF, seq=10003999](https://ncic.re.kr/inv/org/download.do?year=2024&seq=10003999&orgType=ogi4).
- 파일: 1,943,652바이트, 96페이지, SHA-256 `54af8340687ace3599f5242dcc6d4d95382af24144be186fa6c4b246417d0487`.
- 2022본과 2024본의 3~4학년군 성취기준 13개를 코드별로 대조했다. 12개는 동일하고 **[4음02-05]의 ‘음악 문화유산’이 ‘음악 국가유산’으로 바뀌었다.** 따라서 ‘중고등학교에만 영향을 주고 초등은 동일하다’고 말할 수 없다.
- 개정 원문 [4음02-05]는 PDF 16페이지(인쇄 10쪽)이며 국가유산을 찾아 듣는 내용이다. 해설이 있는 PDF 17페이지에서도 같은 용어 개정이 확인된다.
- PDF 15~18페이지의 본문을 공백 제거 후 전체 대조했다. 차이는 `문화유산 → 국가유산` 치환 네 곳뿐이었고, 해당 치환 후 두 본문 문자열이 완전히 일치했다. 성취기준 개수나 수행 내용의 다른 변경은 이 구간에서 발견되지 않았다.
- `arts-ethics.json`의 음악 12개 페이지 전체 `verifiedStandards`와 공식 `sources`를 **2024 일부개정 PDF 원문·URL·페이지로 갱신**했다. music-11은 ‘음악 국가유산’을 직접 사용하고 실제 듣기 활동이 분명하도록 목표·예시·활동 문구도 보완했다.
- 지역 예시인 강릉농악은 [국립무형유산원 공식 기록 안내](https://iha.go.kr/service/search_all_item_view.nihc?content_type_=GT01000001&contentid=10342&filetypeid=0&itemid=323&media_type=text)에서 국가무형유산·전통적 공연예술/음악임을 확인했다. 원본 영상·음원을 복제하지 않고 공식 소개 링크만 제공한다.

위의 최초 2022 고시본 검증 기록은 비교 이력으로 보존하며, 실제 음악 페이지의 원문 표시는 이 추가 대조 결과인 2024 일부개정본을 따른다. 도덕·체육·미술의 개별 교과 후속 변경 전수 검토를 새로 수행했다는 뜻은 아니다.

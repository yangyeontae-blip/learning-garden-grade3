# 수학·과학 3학년 연간 학습자료 근거와 검증

확인일: 2026-10-29. 설명·예시·문제·해설은 이 프로젝트에서 새로 작성했다. 교과서 본문·기존 문제·그림은 학생 웹페이지에 복제하지 않았다.

## 결과

- `dist/data/math-science.json`: 수학 28개, 과학 25개, 총 53개 학습자료와 159개 문항.
- 모든 학습자료는 설명 2문단, 예시, 정확히 3문항과 정답·해설을 가진다. 활동형에는 예시 답안과 확인 기준이 있다.
- 학습자료의 연결 기준은 3~4학년군 국가 성취기준이다. 3학년 배정은 별도로 공개된 **아이스크림·미래엔 2022 개정 3-1/3-2 목차 이미지 8개를 실제로 열어 비교**했다.
- 연간 12개 수학 단원과 8개 과학 단원을 모두 포함한다. 각 페이지는 핵심 목표 단위 복습자료이며 모든 교과서 차시·실기·탐구를 대체한다는 의미는 아니다.

## 확인한 공식 자료

- 과학: 같은 고시 별책 9 과학과 교육과정, NCIC 원본. https://ncic.re.kr/inv/org/download.do?year=2022&seq=10003551&orgType=ogi4
- 수학 원본 SHA-256: `ba7c7c63ad31ba0fd32e5eb8148d696dd73288acce111495c593298112f8f840`
- 과학 원본 SHA-256: `0cf53427691d54366d6805767c428a15b0e817580807b4354947de7e3b58b738`
- 두 해시는 설치된 MCP 데이터의 `curriculum-standards.json`에 기록된 원본 해시와 일치한다.

MCP의 `get_learning_roadmap`, `get_standard`, `get_topic`을 사용하여 구조·기준·학습 주제의 관계를 확인했다. MCP 원문에 다음 소제목이나 탐구활동이 이어 붙는 현상이 있어, 학생 자료에 사용하는 기준 문장은 다운로드한 공식 PDF에서 **코드 이후 해당 성취기준의 문장 끝까지 추출**하여 대조했다. 각 페이지의 `verifiedStandards`에 코드·원문·URL·PDF 쪽 번호를 제공한다. 쪽 번호는 표지부터 세는 PDF의 1-based 쪽이며 인쇄 쪽 번호와 다르다.

- 수학 연결 기준의 공식 PDF 위치: 23~24쪽(수와 연산), 26~27쪽(도형과 측정), 29쪽(자료와 가능성).
- 과학 연결 기준: 19~24쪽, [4과01-01]~[4과08-03]의 25개 성취기준 전부.
- 기본 원문은 위 2022 고시 문서이다. 모든 후속 고시를 법령 단위로 전수 비교했다는 주장은 하지 않는다.

## 내용·정답 검증

- 수학 84문항의 문제·예시·설명을 다시 읽어 계산 원리, 그림 없는 질문의 성립 여부, 단위를 확인했다.
- `scripts/audit-math-science.py`에서 **51개 수치·분수·시간·단위변환 정답을 독립적으로 다시 계산**하여 실제 JSON 정답과 일치함을 확인했다. 받아내림 시간 계산, kg↔g, L↔mL, 몫·나머지, 나머지가 있을 때 필요한 차의 수를 포함한다.
- 수학 나머지 설명형·도형형 문항의 답과 모든 과학 75문항의 예시 답안·해설·활동 기준을 수작업으로 다시 확인했다.
- 과학 활동은 생명 존중, 위험한 물·물질을 맛보지 않기, 큰 소리를 귀 가까이 내지 않기, 물때·보호자 안내 등을 해당 활동 맥락에서 포함했다. 실제 감염병 진단이나 치료 안내는 하지 않는다.
- 구조 검사: 53개 고유 ID, 페이지당 3문항, 객관식 정답이 선택지에 정확히 1회 존재, 활동형 기준 최소 8자(실제 최솟값 20자).
- 근거 검사: JSON의 모든 `verifiedStandards.text`가 지정한 공식 PDF 쪽의 정규화된 문장과 일치함을 자동 확인했다.
- 전문 교사의 독립 검수를 받았다는 표시는 하지 않는다. 실기·탐구의 실제 수행을 웹문항만으로 평가했다고 표시하지 않는다.

## 재생성 참고

`scripts/author-math-science.py`는 확인한 공식 PDF를 `research/math-science-sources/`에서 읽어 학습 JSON을 작성한다. `scripts/audit-math-science.py`는 수치 정답과 PDF 근거를 재검증한다. 실행에는 Python의 PyMuPDF가 필요하다. 공식 PDF와 출판사 이미지 원본은 검증용 로컬 캐시이며 GitHub 학생 사이트나 저장소에 재게시하지 않는다. 재검증하려면 위 NCIC URL에서 원본을 내려받아 `math-official.pdf`, `science-official.pdf`로 저장하면 된다.

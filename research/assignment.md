# 대학원 과제: 교육과정 MCP에서 학습자료까지

## 제출 주소

1. Public GitHub 저장소: https://github.com/yangyeontae-blip/learning-garden-grade3
2. GitHub Pages 과제 안내: https://yangyeontae-blip.github.io/learning-garden-grade3/#assignment
3. 대표 학습자료: https://yangyeontae-blip.github.io/learning-garden-grade3/#lesson=math-01

패들릿에는 1번과 2번을 함께 제출한다. 과제 안내 페이지에서 대표 단원과 근거·제작 과정을 확인할 수 있다.

## 선택과 범위

- MCP: [초등 교육과정 MCP](https://github.com/taehyeonglim/korean-elementary-learning-map-mcp)만 사용. 중등 MCP는 사용하지 않았다.
- 대표 교과·단원: 초등 3학년 1학기 수학, 덧셈과 뺄셈.
- 학습자료: `math-01` 세 자리 수를 더해요, `math-02` 받아내림이 있는 뺄셈. 각각 설명·예제·3문항·정답/해설.
- 원래 요청에 따라 제작한 9개 교과 157개 자료는 확장 자료로 유지했다. 과제의 대표 분석 대상은 위 단원으로 명확히 지정했다.

## 실제 MCP 사용

Codex 사용자 설정에 `curriculum-kr` stdio 서버를 등록했다. 최초 연결과 도구 9개 로딩·실제 조회 동작을 확인했다.
전체 제작 때 `get_learning_roadmap`, `get_standard`, `get_topic` 등으로 기준과 세부 주제·관찰 증거를 확인했다.
대표 단원에 대한 아래 조회는 2026-10-29에 연결된 MCP 도구를 다시 직접 호출하여 입력과 응답을 저장했다.

```json
{"tool":"get_standard","input":{"code":"4수01-03"}}
{"tool":"get_topic","input":{"topicId":"kr.mt.math.number-operations.g3-4.s4-01-03.concept"}}
```

응답과 원문 교정 내역: [`dist/data/mcp-assignment-trace.json`](../dist/data/mcp-assignment-trace.json).

## 성취기준과 근거 검증

공식 성취기준 [4수01-03]: 세 자리 수의 덧셈과 뺄셈의 계산 원리를 이해하고 그 계산을 할 수 있다.

- 공식 근거: [교육부 고시 제2022-33호 수학과 교육과정, NCIC 공개 PDF](https://ncic.re.kr/inv/org/download.do?year=2022&seq=10003559&orgType=ogi4#page=23), PDF 23쪽.
- MCP는 3~4학년군 기준이므로 3학년 배정은 아이스크림·미래엔 2022 개정 3학년 1학기 공개 목차와 별도 대조했다. 상세 링크는 두 학습자료의 `sources`와 `math-science.md`에 있다.
- 실제 MCP의 `officialText` 끝에는 다음 제목 ‘세 자리 수 범위의 곱셈’이 혼입되어 있었다. 공식 PDF와 대조하여 그 제목을 성취기준 문장에서 제외했다. MCP 조회 결과를 검증 없이 복사하지 않았다.

## 성취수준의 성격

조회한 MCP는 공식 성취기준과 세부 주제의 관찰 증거·평가 발문을 제공했지만, 공식적인 수준별 성취수준표는 제공하지 않았다.
따라서 사이트의 ‘도움 필요·도달·확장’은 **이 자료를 위해 작성한 자체 확인 기준**이다. 국가에서 고시한 성취수준이나 공식 평가 도구라는 표시를 하지 않는다.

| 자체 수준 | 관찰 증거 |
|---|---|
| 도움 필요 | 자릿값을 맞추거나 받아올림/받아내림을 수행할 때 도움이 필요함 |
| 도달 | 두 계산·생활 문제를 스스로 해결하고, 세 번째 문항에서 받아올림 원리 또는 검산 관계를 드러냄 |
| 확장 | 도달 수준에 더해 새로운 수에서도 원리를 설명하고 오류를 찾아 수정함. 추가 관찰이 필요하며 세 문항 정답 수만으로 자동 판정하지 않음 |

MCP `get_topic`의 `assessmentPrompt`는 핵심 개념을 자신의 말과 간단한 예로 설명하도록 권한다. 이를 반영해 덧셈 3번은 받아올린 1의 뜻을 설명하고, 뺄셈 3번은 덧셈으로 검산하도록 구성했다.

## 문항과 기준의 연결

| 자료 | 1번 | 2번 | 3번 |
|---|---|---|---|
| math-01 | 326+241 기본 계산 | 도서관 책 268+157권 상황 적용 | 185+237에서 십의 자리로 받아올린 1의 뜻 설명 |
| math-02 | 563-241 기본 계산 | 스티커 600-275장 상황 적용 | 500-146 계산 후 덧셈 검산 |

모두 [4수01-03]과 연결한다. 계산 결과만 맞는지 확인하는 데서 끝나지 않고 자릿값·계산 원리·덧셈과 뺄셈 관계의 증거를 함께 보려는 설계다.

## 제작 과정에서 실제 확인한 문제

1. 학년군만으로 3학년 또는 학기를 정할 수 없었다. 공개 교과서 목차 대조가 필요했다.
2. MCP 원문 추출에 다음 제목이 붙는 오류가 있었다. 공식 PDF의 원문 경계를 확인해야 했다.
3. 성취기준과 공식 성취수준은 같은 데이터가 아니었다. 자체 관찰 기준의 출처·성격을 명시해야 했다.
4. 기준을 조회했다고 문항의 정답까지 보장되지 않았다. 수학의 수치·분수·단위·시간 정답을 독립 재계산했다.
5. 제작 때 MCP를 활용하는 것과 브라우저 방문자가 실시간 MCP를 호출하는 것은 달랐다. 이 사이트는 확인한 학습자료를 정적 JSON으로 제공한다.
6. 계획 후 구현, 출처 대조와 실제 브라우저 점검, Public 저장소 push, GitHub Actions/Pages 공개 배포를 거쳐야 결과를 확인할 수 있었다.
